# Hand Landmarker

`hand_landmarker.task` is Google's full float16 Hand Landmarker model, downloaded
from the official MediaPipe model catalog on 2026-09-16.

Source: https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/latest/hand_landmarker.task

SHA-256: `fbc2a30080c3c557093b5ddfc334698132eb341044ccee322ccf8bcf3607cde1`

Usage and model information:
https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker

The bundled model runs locally. Camera images are neither saved nor uploaded.
